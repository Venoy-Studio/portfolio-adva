# Portfolio • ADVA Rastreamento Veicular

Clone autêntico da landing page **ADVA Rastreamento Veicular** adaptado para fins de portfólio e demonstração profissional, com dados e contatos fictícios para preservação de privacidade.

---

## 🚀 Como Visualizar o Projeto

### Opção 1: Abrir direto no navegador
Basta dar duplo clique no arquivo [`index.html`](file:///c:/Users/paulovenoy/Documents/antigravity/serene-bose/index.html) ou abri-lo pelo seu navegador favorito.

### Opção 2: Servidor local (Node.js)
```bash
npm start
# ou
npx serve -l 3000 .
```
Acesse `http://localhost:3000`.
